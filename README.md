## 프로젝트 개요
(주)하이테커 강남지사(고용노동부 지정 위탁운영기관)의 **2026 청년일자리도약장려금** 사업을 소개하는 정적 랜딩 페이지입니다. 이전 담당자가 제작한 페이지를 기반으로, 연락처 정보를 최신화하고 FAQ 이동 방식을 새 창(새 탭) 링크 방식으로 개선했습니다.

## 완료된 기능
1. **사업 소개 메인 페이지 (`index.html`)**
   - 사업 개요, 지원 내용(1인당 최대 720만원), 기업 지원 요건
   - 채용 청년 근로 조건 및 2026년 최저임금 기준표
   - 지원 대상 청년 자격 조건(취업애로유형 10가지 포함)
   - 사업 참여 프로세스(3단계) 안내
   - 참여 문의 및 연락처 섹션
2. **버튼 2개**
   - **"사업 참여 사전신청 하기"** 버튼 → 구글 신청폼(`https://forms.gle/M7Vakm7vTLzc253f8`)으로 새 창 연결 (`target="_blank"`)
   - **"자주 묻는 질문(FAQ) 보러가기"** 버튼 → 같은 프로젝트 내 `faq.html`을 새 창으로 오픈 (`target="_blank"`)
3. **FAQ 페이지 (`faq.html`)**
   - 아코디언(접고 펼치기) 방식의 자주 묻는 질문 15개 안내
   - 메인 페이지의 FAQ 버튼 클릭 시 새 탭으로 열림
4. **연락처 정보 최신화**
   - 기존 3개 번호(02-6953-2313 / 02-6235-5079 / 02-6953-9350) 및 이메일 안내를 **전화번호 2개 + 이메일 1개**로 통일
     - 전화 : `02-6953-2313` / `02-6953-4203`
     - 이메일 : `jump_work@kfo.or.kr`
   - 메인 페이지 문의 섹션, 푸터, FAQ 페이지 하단 문의 안내, FAQ 페이지 푸터까지 모두 동일하게 반영
   - 전화번호는 클릭 시 바로 전화 연결되는 `tel:` 링크, 이메일은 클릭 시 메일 작성창이 뜨는 `mailto:` 링크로 처리 (모바일/PC 접근성 향상)
5. **참여 기관 로고 노출 (하단 푸터)**
   - (주)하이테커 강남지사 · 이노비즈협회(컨소시엄) 통합 로고를 메인 페이지 및 FAQ 페이지 하단 푸터에 배치
   - 연락처(전화/이메일)와 Copyright 문구를 함께 표시, 불필요한 여백/구분선을 제거해 깔끔하게 정리
6. **"빠른 공유 링크" 호환성 개선**
   - 빠른 공유 링크 방식은 `css/style.css` 같은 별도 파일을 함께 서빙하지 않아, 폰트/스타일이 깨지는 문제가 있었습니다.
   - 이를 해결하기 위해 `css/style.css`의 모든 내용을 `index.html`, `faq.html` 각각의 `<style>` 태그 안에 직접 내장(inline)했습니다. 이제 각 HTML 파일이 외부 CSS 파일 없이도 완전하게 자체적으로 렌더링됩니다.
   - (참고) 로고 이미지(`images/footer-logo.png`)는 여전히 프로젝트 내 로컬 파일을 참조합니다. 파일 탐색기 다운로드 및 Publish(호스팅 배포) 방식에서는 이미지가 정상적으로 표시되나, 빠른 공유 링크 방식에서는 이미지 파일 접근 제약으로 로고가 표시되지 않을 수 있습니다. 안정적인 이미지 표시가 필요하시면 Publish 탭을 통한 배포를 권장드립니다.

- 빠른 공유 링크 환경에서 로고 이미지가 표시되지 않는 경우, 이미지까지 완전히 배포 환경에 독립적으로 만들려면 외부에서 안정적으로 접근 가능한 이미지 호스팅 URL로 교체하는 방법이 있습니다. 필요 시 알려주시면 진행하겠습니다.

STEP 1

제출 서류 준비

신청서 작성 마지막 단계에서 아래 3가지를 첨부합니다. 미리 준비해 두시면 한 번에 끝낼 수 있습니다.

1
사업자등록증
신청서의 ‘사업개시일’에 등록증의 개업연월일을 그대로 입력합니다.
2
부가가치세 과세표준증명원 (2025년 또는 2024년)
홈택스에서 발급 가능합니다. ※ 업력 1년 미만 · 면세법인사업자 · 고유번호증 소유 기업은 제외
3
[붙임1] 신청서식 일체 작성·서명 필요
  • 사업주 확인서 (서식 1-1)
  • 개인정보 수집·이용 동의서 – 사업주용 (서식 3)
  • 중소기업 지원사업 통합관리시스템 정보 활용 동의서 (서식 4)
⬇ 한글(HWP) ⬇ 워드(DOCX) ⬇ PDF (출력용)

STEP 2

고용24 접속 · 로그인

반드시 ‘기업’ 탭에서 기업회원으로 로그인해 주세요.

  • 고용24 상단 [기업] 탭 → 우측 상단 [로그인]
  • 메인 화면 [고용장려금] 탭 → [청년일자리 도약장려금] 선택
  • [참여신청관리] 탭 하단의 [사업참여신청] 버튼 클릭
이미지를 누르면 크게 볼 수 있습니다
고용24 바로가기
STEP 3

참여신청서 작성

신청서는 한 페이지로 이어져 있습니다. 아래 순서대로 입력해 주세요.

① 운영기관 선택 · 대표 사업장 등록

담당 운영기관 칸 옆 [운영기관 검색] 클릭 → ‘하이테커 강남지사’ 선택 (필수)
  • 고용보험 사업장관리번호: [관리번호 검색] 클릭 → 조회된 관리번호 클릭
  • 검색창의 ‘비수도권 산단입주기업’은 체크하지 않습니다 (강남구는 수도권)
  • 사업참여유형: 본사만 있으면 사업단위 · 지사를 따로 신청·관리하려면 사업장단위
  • 지사도 함께 신청할 경우 ‘관련 사업장 현황’에서 [추가 +]로 지사 등록

② 기준 피보험자 수 · 매출액 입력

  • 지원유형: 수도권 체크
  • 사업개시일: 사업자등록증의 개업연월일 입력
  • 매출액: 부가가치세 과세표준증명원의 ‘계’ 금액 합계 입력
  • 매출액 시작일 · 종료일: 과세표준증명원의 과세기간과 동일하게 입력

③ 기업 구분 · 채용계획 · 서류 첨부

  • 기업구분: 해당되는 항목 모두 체크 (일반적으로 우선지원대상기업)
  • 채용계획 근무시간: 주 28시간 이상 · 월급여: 최저임금 이상 ~ 450만원 이하
  • 신청일 직전 3개월 이내에 이미 채용한 청년이 있으면 ‘채용자 정보’에 체크 후 입력
  • 첨부파일: STEP 1의 서류 3종을 [첨부파일 등록]으로 업로드 → 서식 다시 받기

④ 사업주 확인서 (화면 내 체크)

  • 지원제외 기업 ①~⑨: 모두 ‘아니요’
  • 지원제외 청년 ①~⑪: 모두 ‘확인’
  • 하단 확인 문구: ‘예’

⑤ 개인정보 수집·이용 동의 후 제출

  • [전문보기] 클릭 → 대표자 성함 · 주민등록번호 입력 → [동의]
  • ‘동의합니다’ 선택 후 신청서 제출
